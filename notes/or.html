Module 1: Linear Programming Problem (9 Qs)

Q1. LPP Formulation (Milk Plant)
A milk plant manufactures two types of products A and B... Profit Rs. 5 on A, Rs. 3 on B. Processing time: A needs 1 min on G, 2 min on H. B needs 1 min on G, 1 min on H. Machine G available 6h 40m, H available 8h 20m. Formulate to maximize profit.

Step 1: Variables

Let x₁ = units of A, x₂ = units of B.

Step 2: Objective Function

Maximize Z = 5x₁ + 3x₂

Step 3: Constraints (Convert to Minutes)

Machine G: 6h 40m = (6×60)+40 = 400 mins. → 1x₁ + 1x₂ ≤ 400
Machine H: 8h 20m = (8×60)+20 = 500 mins. → 2x₁ + 1x₂ ≤ 500

Step 4: Non-negativity

x₁, x₂ ≥ 0

Q2. LPP Formulation (Animal Feed)
Produce 200 kg of mixture of A and B. Cost A=Rs 3/kg, B=Rs 8/kg. Max 80 kg of A can be used, min 60 kg of B must be used. Minimize cost.

Step 1: Variables

Let x₁ = kg of ingredient A, x₂ = kg of ingredient B.

Step 2: Objective Function

Minimize Cost Z = 3x₁ + 8x₂

Step 3: Constraints

Total Mixture: x₁ + x₂ = 200
Maximum A: x₁ ≤ 80
Minimum B: x₂ ≥ 60

Step 4: Non-negativity

x₁, x₂ ≥ 0

Q8. Simplex Table Analysis

Given a partially solved simplex table, we analyze it.

(a) Calculate Zj values:

Since Basic Variables are all slack (s₁, s₂, s₃) with cost 0, Zj = Σ(C_B * X_j) = 0 for all columns.

(b) Calculate Δj (Zj - Cj):

Δ(x₁) = 0 - 4 = -4. Δ(x₂) = 0 - 3 = -3. Δ(x₃) = 0 - 2 = -2.

(c) Calculate Replacement Ratio:

Most negative Δj is -4 (Column x₁). Entering variable is x₁. We calculate Ratio = RHS / x₁ column value to find leaving variable.

(d) Check Optimality:

For Maximization, table is optimal ONLY if all Δj ≥ 0. Since we have negative values (-4, -3, -2), the solution is NOT Optimal.

Q9. Big M Table Analysis

Given a Minimization Big M table.

(a) Identify Basic Variables & Cost:

From the C_B column: s₁ (Cost = 0), A₁ (Cost = M), A₂ (Cost = M).

(b) Check Optimality:

For Minimization, table is optimal ONLY if all (Cj - Zj) ≥ 0. In the table, value under x₁ is (5-7M). Since M is a very large positive number, (5-7M) is highly negative. Thus, NOT Optimal.

(c) Leaving and Entering Variables:

Most negative (Cj-Zj) is (5-7M), so x₁ is the Entering Variable. Ratios (RHS/x₁): s₁=12/4=3, A₁=10/2=5, A₂=10/1=10. Minimum positive ratio is 3. So, s₁ is the Leaving Variable.

Q4. MODI Check Optimality

Check rule: Δij = Cij - (ui + vj)

First calculate ui, vj for allocated cells. Then check unallocated cells.
For unallocated cell (S1,D3), calculate Δ₁₃ = C₁₃ - (u₁ + v₃). Here C₁₃ = 8, u₁ = 0, v₃ = 10.
Δ₁₃ = 8 - (0+10) = -2.

Kyunki Δ value negative (-2) aayi hai, iska matlab solution NOT Optimal hai.

Q5. MODI Check Optimality

Checking the given Basic Feasible Solution

Pehle check karenge m+n-1. Table me 3 Rows aur 3 Cols hain. m+n-1 = 5.
Lekin table me allocated cells check karne par pata chalta hai ki agar wo loop form kar rahe hain (closed circuit), toh direct MODI test nahi lag sakta. Solution Degenerate ya Invalid BFS hoga.

Q6. MODI Check Optimality

Check empty cells (Δij)

Sabhi unallocated (empty) cells ka Δij = Cij - (ui + vj) calculate kiya. Sabhi values zero (0) ya positive (+) aayin.
(Example: S1D3=4, S2D1=5, S3D1=3, S3D2=3).

Kyunki koi bhi value negative nahi hai, isliye diya gaya solution Optimal (Best) hai.
